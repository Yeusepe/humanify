## Bun app directories

- `api-bun`
- `bot-bun`
- `dashboard-start`
- `verifier-start`

These directories now contain the first installable Bun-side runtime skeletons:

- `api-bun`: Elysia health and contract-summary surface
- `bot-bun`: Discord client bootstrap guarded by environment configuration
- `dashboard-start`: TanStack Start + HeroUI dashboard shell
- `verifier-start`: TanStack Start + HeroUI verifier shell
